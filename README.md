Aplicação que converte valores em reais para outras moedas, mostrando o resultado no formato de cada país.

## O que o projeto faz
- Converte de real para dólar, euro, libra, iene, won e bitcoin
- Mostra a bandeira e o nome da moeda escolhida
- Formata os valores no padrão de cada país
- Atualiza o resultado ao trocar a moeda ou clicar em "Converter"

> As cotações são valores fixos de exemplo, e não em tempo real.

## O que pratiquei
- Manipulação do DOM e eventos (`click` e `change`)
- Formatação de moeda com `Intl.NumberFormat`
- Condicionais para trocar texto e imagem de cada moeda
- Layout responsivo com Flexbox
